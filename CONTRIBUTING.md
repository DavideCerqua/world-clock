# Contributing

Thank you for helping improve World Clock Dashboard.

## Development workflow

1. Fork the repository and create a focused branch.
2. Install dependencies with `npm ci`.
3. Make your change without committing generated files or credentials.
4. Run `npm run check`.
5. Open a pull request describing the behavior changed and how it was tested.

Keep pull requests small where possible. For visual changes, include before and after screenshots. New dependencies should have a clear maintenance or user-facing benefit.

## Reporting bugs

Include reproduction steps, expected and actual behavior, browser and operating-system versions, and any relevant console output. Remove personal data and secrets before posting logs.
